# Contributing

Keep this a thin native integration SDK over the official MCP libraries. Protocol framing, negotiation, serialization and transports belong upstream. App UI, model inference and Cully policy belong in the consuming application.

Use JDK 17/Maven 3.9+ for Kotlin and Swift 6.1+ for Apple code. Run `mvn -B verify`, `swift test --jobs 4` with Xcode, and `swift run --jobs 4 MCPMobileCheck`. Tests must use local fixtures by default. Live Cully tests are opt-in, read-only and must not log response content or credentials.

Cover lifecycle, cancellation, authentication failures and the absence of unintended action replay. Preserve upstream result fields and pagination. Add no automatic offline action queue. Document native lifecycle ownership and callback threading. Never infer that timeout/cancellation rolled back a remote action.

Update README, changelog and verification evidence when behavior changes. Release assets are generated by `scripts/package_release.py`; runtime jars resolve using the POM rather than being bundled in an opaque fat jar. Keep dependency versions explicit and review their notices.
